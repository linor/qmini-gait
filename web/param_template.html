Joint angles vs safe limit

The pose-blending viewer (gait_blend.html) interpolates baked joint angles. This one interpolates the gait sample — Tab. 1 time intervals, Sec. 4.3 attributes and the control points of every Tab. 2 function curve — into a new valid sample, then runs the planner on it: footholds sampled from the predicted path frame and latched at touchdown, swing curves clamped to the foothold, heel-toe rig, and a 5-DoF damped-least-squares IK per leg per frame.

Consequences you can watch: travelled velocity equals the command exactly (the path frame is its integral), swing clearance never goes negative, and planted feet do not slide. The failure mode moves to the IK residual — if a blended gait asked for something the legs cannot reach, that number would rise and the joint bars would saturate.
